Маршруты бригад

Адреса → поиск на карте → деление между рабочими → оптимальный порядок по дорогам → ссылка на маршрут

Как пользоваться
  1. Заполните таблицу. Населённый пункт выберите из списка: ближайшие к Майкопу стоят сверху, можно начать печатать название. Улицу и дом впишите.
  2. Enter — новая строка, регион и населённый пункт подставятся сами.
  3. Если у заказа есть время (8:00, 9:30, до 11:00), выберите его: такой заказ поедет первым в маршруте.
  4. Укажите число рабочих и нажмите «Построить маршруты». Адреса из оранжевого блока «Проверьте» поправьте.
  5. Каждому рабочему нажмите «Скопировать для мессенджера» и отправьте.
Текст, распознанный с фото, — кнопка «Вставить списком». Пустой бланк для диспетчеров — кнопка «Бланк для печати».
Ключи Яндекс Карт (настраиваются один раз на каждом компьютере)
  1. Откройте developer.tech.yandex.ru и войдите с вашим Яндекс ID.
  2. Нажмите «Подключить API» и подключите два продукта: «JavaScript API» (карта и маршруты) и «HTTP Геокодер» (поиск адресов). У каждого будет свой ключ.
  3. У ключа «JavaScript API» в поле «Ограничение по HTTP Referer» укажите адрес этого сайта без https:// (например, kalimandmitriy-droid.github.io).
  4. Вставьте оба ключа в поля ниже и нажмите «Сохранить». Ключи хранятся только в этом браузере и начинают работать примерно через 15 минут после получения.
